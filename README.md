## 🔥 شو الميزات الأساسية؟
- **مجلد لكل مادة:** بتعمل مجلد لكل مادة بتدرسها، بتحدد اسمها ولونها وكودها، وكل محاضراتها بتضل مرتبة جواتها.
- **تأثيرات وشاشة انتظار ممتعة قبل فتح الملف:** عبارات حماسية وعامية للطلاب مع شريط ألوان جوجل المتوهج وحركة نبض بألوان الملف.
- **وضع ملء الشاشة الشامل:** بكبسة زر بتقدر تحول عرض أي ملف (سلايدات، وورد، إكسل، PDF، كود، صور) لوضع ملء الشاشة لتركز بالدراسة بدون أي مشتتات.
- **الملفات بتفتح متل ما هي:** محرك عرض مخصص بيفتح سلايدات الـ PPTX وملفات الوورد والإكسل والـ PDF بدون ما يخرب التنسيق، مع إمكانية تكبير وتصغير ونسخ النصوص بسهولة.
- **توافق 100% مع الجوال:** تجربة سلسة ومتكاملة على كل شاشات الهواتف (آيفون، أندرويد، تابلت) مع قوائم جانبية ذكية تتجاوب مع اللمس.
- **كل شي محفوظ على جهازك:** ما بنرفع أي ملف لأي سيرفر، كل موادك وملفاتك وملاحظاتك بتتخزن عندك محلياً بأمان تام عبر المتصفح (IndexedDB).
- **دفتر ملاحظاتك:** لوحة جانبية خفيفة بتسجل فيها ملاحظاتك وتلخيصاتك أثناء الدراسة، وبتنحفظ تلقائياً وتقدر تنزلها كملف نصي بأي وقت.
