تطبيق ويب مصمم بأسلوب جوجل وأبل الحديث ومطابق لمعايير واجهات 2026، معمول مخصوص لطلاب الجامعات عشان ترتب كل مادة ومحاضراتها لحال، وتفتح سلايدات البوربوينت والوورد والإكسل والفيديوهات والـ PDF بنفس شكلها الأصلي وبدون ما تخرب وبدون نت.

## 🔥 شو الميزات الأساسية؟
- **مجلد لكل مادة:** بتعمل مجلد لكل مادة بتدرسها، بتحدد اسمها ولونها وكودها، وكل محاضراتها بتضل مرتبة جواتها.
- **تأثيرات وشاشة انتظار ممتعة قبل فتح الملف:** عبارات حماسية وعامية للطلاب مع شريط ألوان جوجل المتوهج وحركة نبض بألوان الملف.
- **مشغّل فيديوهات دراسي ذكي:** تشغيل جميع صيغ الفيديوهات والمحاضرات المسجلة (MP4, WebM, MKV, MOV, AVI)، مع أزرار تسريع المحاضرة (0.75x, 1x, 1.25x, 1.5x, 2x)، وتقديم/ترجيع 10 ثواني، وميزة النافذة العائمة (Picture-in-Picture) لمشاهدة المحاضرة وكتابة الملاحظات بنفس الوقت.
- **مشاركة الملفات المباشرة (Native Sharing):** بكبسة زر بتقدر تشارك أي ملف أو سلايدات من التطبيق مباشرة عبر الواتساب أو التلغرام أو الإيردروب أو جوجل درايف.
- **الملفات بتفتح متل ما هي:** محرك عرض مخصص بيفتح سلايدات الـ PPTX وملفات الوورد والإكسل والـ PDF بدون ما يخرب التنسيق، مع إمكانية تكبير وتصغير ونسخ النصوص بسهولة.
- **وضع ملء الشاشة الشامل:** بكبسة زر بتقدر تحول عرض أي ملف أو فيديو لوضع ملء الشاشة لتركز بالدراسة بدون أي مشتتات.
- **تذكيرات وإشعارات الجوال الذكية:** نظام تنبيهات حقيقي يرسل إشعارات للهاتف وسطح المكتب مع نغمة تنبيه صوتية (Chime)، مع إمكانية ربط التذكير بمادة معينة أو سلايد محدد وتحديد درجة الأهمية ومتابعة المهام المنجزة.
- **شريط تنقل سفلي للموبايل (Bottom Navigation Bar):** تصميم زجاجي عائم مستوحى من أبل وجوجل يتيح تصفح المواد والتذكيرات والملاحظات بإبهام يدك بكل سهولة.
- **شغال أوفلاين 100% بدون نت:** كاش فوري ذكي (Service Worker v2) يحفظ كل الأدوات محلياً، لتفتح وتدرس محاضراتك بالجامعة حتى بدون توفر إنترنت.
- **معايير 2026 للحركة وإمكانية الوصول:** حركات هادئة وذكية غير مبالغ فيها، مع دعم كامل لمعيار تقليل الحركة (`prefers-reduced-motion`) لراحة العين والتركيز.
- **كل شي محفوظ على جهازك:** ما بنرفع أي ملف لأي سيرفر، كل موادك وملفاتك وتذكيراتك بتتخزن عندك محلياً بأمان تام عبر المتصفح (IndexedDB).
- **دفتر ملاحظاتك:** لوحة جانبية خفيفة بتسجل فيها ملاحظاتك وتلخيصاتك أثناء الدراسة، وبتنحفظ تلقائياً وتقدر تنزلها كملف نصي بأي وقت.
